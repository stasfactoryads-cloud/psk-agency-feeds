# Логотипы агентств

Положите сюда файл логотипа с именем `<slug агентства>.<расширение>`.
Подходят `svg`, `png`, `jpg`, `jpeg`, `webp`. Лучше квадратный или близкий к нему, от 128 px.

| Агентство | Имя файла |
|---|---|
| Тренд | `trend.png` |
| Адвекс | `advecs.png` |
| Петербургская недвижимость | `peterburgskaya-nedvizhimost.png` |
| ПАН | `pan.png` |
| Н Маркет | `n-market.png` |

Если файла нет, на странице показывается круг с первыми буквами названия.
Другое имя файла можно указать в `config.toml`: `logo = "имя.png"` в блоке агентства.
